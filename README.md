# Map Page

## About This Project

This project is part of my software and web development course. I'm using it to practise building a webpage that displays a map and presents location information in a clear, organised way.

The aim is to create a simple, responsive page and explore how an embedded map can be included alongside other website content.

## What I'm Working On

- **Embedded maps** – learning how to add a map to a webpage using an embed.
- **HTML structure** – organising the page into clear sections.
- **CSS styling** – adjusting the layout, colours, spacing and typography.
- **Responsive design** – making sure the map and surrounding content work on different screen sizes.
- **Layout techniques** – using Flexbox or Grid to position the map and other elements.
- **Location information** – displaying details such as an address, opening hours or contact information where relevant.
- **Accessibility** – providing suitable headings and accessible labels for the map.

## Technologies Used

- HTML5
- CSS3
- Embedded map (if used)

## What I've Learned

This project gives me the opportunity to practise combining HTML and CSS to create a useful webpage. I'm learning how to embed external content, organise location details and make a layout work across different screen sizes.

I'll continue improving the page as I learn more about web development and responsive design.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. View the map and explore the page layout.

If the map is embedded from an external service, an internet connection may be required for it to load.
